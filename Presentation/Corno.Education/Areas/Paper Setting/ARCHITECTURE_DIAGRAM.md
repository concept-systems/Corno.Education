## Duplicate Prevention Logic

```
For Each Record in Source:
?
?? Extract Key Fields (College, Course, CoursePart, Subject, etc.)
?
?? Query Target Instance for matching record
?
?? IF Found:
    ?? SKIP (increment skipped count)
?
   ELSE (Not Found):
    ?? Create new record
       ?? Copy all fields from source
       ?? Update CreatedBy/Date to current user
       ?? Save to database (increment transferred count)
```

## Threading Model

```
Main Thread (UI)
?
?? User clicks Transfer
?  ?? POST /TransferData (sync response immediately)
?     ?? Returns: {success: true, progressKey: ...}
?
?? Start polling progress every 500ms (non-blocking)
   ?
   ?? GET /GetTransferProgress (async polling)
   ?
   ?? Worker Thread (Background Task)
      ?
      ?? TransferXxxAsync() runs in background
      ?  ?
      ?  ?? Thread-safe: TransferProgressDict (ConcurrentDictionary)
      ?  ?
      ?  ?? Updates progress.Processed, progress.Transferred
      ?  ?
      ?  ?? Polling thread reads these updates
      ?
      ?? Main thread gets updates and shows progress bar
```
